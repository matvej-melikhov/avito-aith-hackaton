# Avito AI Reviewer

Помощь ревьюерам и методистам в организации проверки работ студентов образовательных курсов Авито

Студент может воспользоваться самопроверкой с помощью ИИ перед сдачей работы и получает обратную связь после проверки ревьюером

Ревьюер использует подготовленный ИИ отчет о проверке и выносит вердикт

Методист распределяет работы и следит за сроками

## Стек

- **Фронтенд:** React, TypeScript
- **Бэкенд:** Python, FastAPI, MySQL, MinIO, Redis, Taskiq
- **ИИ-часть:** deepseek-v4-flash, DeepSeek harness

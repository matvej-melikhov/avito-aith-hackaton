## Предварительные метрики

Реальные цифры из интервью с ревьюером Tech QA — не наша гипотеза:

| Метрика | Значение |
|---|---|
| Ручная проверка одной работы | около часа |
| С их собственным навыком для модели | 10–15 минут, ускорение в 4–6 раз |
| Студентов на типовой поток | около 100 |
| Ревьюеров минимум на один тип задания | 5–6 |
| Работ на одного ревьюера | до 20 |
| Доля студентов, которые сдают | около 80% |

**Наш собственный замер: не проведён.** Главная гипотеза («ревьюер принимает черновик, а не переписывает») по плану проверяется 4 сентября на трёх работах системного дизайна, с замером времени вручную и с черновиком. Результата пока нет — появится до финала, см. [12-hypotheses.md](../../docs/12-hypotheses.md).

## Результаты экспериментов

Пока не проведены. Запланированы на 4 сентября: точность черновика по требованиям на трёх работах против ручной разметки, время ревьюера вручную против черновика. Как устроен замер — [10-benchmark.md](../../docs/10-benchmark.md).

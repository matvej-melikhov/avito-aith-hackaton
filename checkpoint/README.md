## Что уже есть в проекте и может пойти в материалы

Ничего не нужно писать с нуля — почти всё уже лежит в `docs/`, вопрос только в отборе и упаковке.

**Продуктовая часть:** [01-product.md](../docs/01-product.md) (для кого, проблема, цена ошибки, почему не просто ChatGPT), [02-as-is.md](../docs/02-as-is.md) (текущий процесс и где болит), [12-hypotheses.md](../docs/12-hypotheses.md) (главная ставка и гипотезы), [06-ux-and-effects.md](../docs/06-ux-and-effects.md) (метрики и эффект в часах).

**Решение:** [03-platform.md](../docs/03-platform.md) (ядро, адаптеры, профили, схема), [08-review-core.md](../docs/08-review-core.md) (три класса требований), [09-assignment.md](../docs/09-assignment.md) (pull-механика), [04-contracts.md](../docs/04-contracts.md) (что нельзя нарушать).

**Подтверждения прогресса:** [макеты 23 экранов](../docs/platform-screens/all-screens.html), [модель данных с ER-диаграммой](../docs/platform-screens/entities-and-screens.md), [расшифровка интервью с ревьюером Авито](../sources/04-review-meeting-transcript.txt), [находки из интервью и данных](../docs/insights.md), история коммитов в ветке `matvej`.

**Чего пока нет и на чекпоинте это будет видно:** работающего кода, замера качества на реальных работах, замера времени ревьюера. Это честно проговариваем, а не прячем.

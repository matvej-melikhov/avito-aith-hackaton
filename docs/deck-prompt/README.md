# Пакет для генерации шаблонов презентации

Что скормить внешнему инструменту, чтобы получить библиотеку из 18 шаблонов
слайдов. Пакет самодостаточный: исполнителю не нужен доступ к репозиторию, все
значения и правила лежат внутри файлов.

## Как пользоваться

1. Открой [00-prompt.md](00-prompt.md) и скопируй его целиком в инструмент.
2. Приложи к нему три файла контекста и эталон разметки:

| Файл | Зачем нужен |
|---|---|
| [01-style.md](01-style.md) | цвета, шрифты, размеры, геометрия. Числа явные, чтобы исполнитель не подбирал на глаз |
| [02-pitch-rules.md](02-pitch-rules.md) | правила Demo Day. По ним выставляют баллы, шаблоны обязаны им соответствовать |
| [03-content-facts.md](03-content-facts.md) | наш продукт и проверенные факты. Шаблоны наполняются отсюда, а не рыбой |
| [04-reference-slide.html](04-reference-slide.html) | эталон разметки: скелет кадра, метки чисел, разметка слотов. Открывается в браузере |

3. Получи один HTML-файл и положи его в `docs/design/`.

Если инструмент принимает только текст без вложений, склей файлы подряд в
одно сообщение в порядке: промпт, стиль, правила, факты, эталон.

## Что на выходе

18 шаблонов: десять строгих рабочих и восемь смелых ударных. Плюс библиотека
SVG-графики и оформленные места под растр и видео. Каждый заменяемый кусок
подписан как слот, подписи снимаются одним переключателем.

## Откуда взяты правила

- Стиль — из дизайн-системы проекта, `docs/design/tokens.css` и
  `docs/design/design-pack.md`. Значения продублированы числами.
- Правила питча — из `sources/demo-day-pitch-guide.pdf`, гайд организаторов.
- Факты и числа — из `docs/insights.md`, интервью с ревьюером курса Tech QA.

## Что здесь уже есть готового

Если шаблоны нужны прямо сейчас и без внешнего инструмента, в репозитории уже
лежит [../design/deck.html](../design/deck.html): кит компонентов слайда и
восемь пресетов страниц на тех же токенах. Этот пакет нужен, чтобы получить
библиотеку шире и с более смелой графикой.

## Правило про числа

Оно повторено в каждом файле пакета и повторяется здесь. Рядом с любым числом
на слайде стоит метка: **замер**, если число получено на данных, **цель**, если
порог объявлен заранее и ещё не подтверждён, **допущение**, если это оценка.
Число без метки на слайд не ставится. Это правило репозитория и одновременно
требование гайда отделять измеренное от гипотезы.

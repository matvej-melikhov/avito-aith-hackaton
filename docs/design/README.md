# Дизайн

Как выглядит платформа. Стиль собран по ребрендингу Авито 2024 и вёрстке start.avito.ru.

| Файл | Зачем |
|---|---|
| [design-pack.md](design-pack.md) | правила словами: цвет, шрифты, геометрия, компоненты, паттерны, антипаттерны, чеклист приёмки |
| [tokens.css](tokens.css) | все значения переменными. Единственный источник цветов и размеров |
| [components.css](components.css) | библиотека компонентов |
| [kit.html](kit.html) | живой кит, каждый компонент во всех состояниях |
| [screens.html](screens.html) | пять экранов платформы на новом стиле |
| [style-options.html](style-options.html) | три варианта стиля, из которых выбрали A. История решения |

Экраны в прежнем оформлении и вся логика статусов лежат в [../platform-screens/](../platform-screens/), они остаются источником содержания.

Правило: в разметке не должно быть ни одного HEX и ни одного размера мимо `tokens.css`.

# Адресные предложения UX/UI

Готовый файл: [../ux-review.html](../ux-review.html). Открывается отдельно от папки: исходные экраны и стили встроены. Для оригинальных шрифтов нужен доступ к Google Fonts, иначе используются системные замены.

Внутри — десять вариантов «было / стало», подсветка изменённых блоков, одинаковая ширина сравнения, просмотр 100% и реестр всех 22 экранов. «Было» извлекается из текущего `screens.html`, а не воссоздаётся по памяти. Отпечаток исходного файла указан в панели. Предложения сохраняют исходную палитру, геометрию, композицию ролей, данные и порядок требований.

## Из чего собирается

- `build.mjs` извлекает исходные экраны и CSS, собирает автономный HTML.
- `cases.js` содержит обоснования, реестр 22 экранов, адресные преобразования и локальные взаимодействия прототипа.
- `proposal.css` содержит только добавочные стили предложений, использует токены проекта.
- `viewer.html` и `viewer.css` — оболочка сравнения, визуально отделённая от продукта.

Пересборка из корня проекта: `node docs/design/ux-review/build.mjs`. Дополнительные пакеты для сборки не нужны. Скрипт перезаписывает только `docs/design/ux-review.html`; исходные `screens.html`, `tokens.css`, `components.css` не изменяет.

## Границы предложений

Нет нового автосохранения, автоматической оценки качества рубрики, новых KPI, переноса карточки решения вправо или объединения разделов. Сложные вопросы — зачёт ниже порога, вес добавленного требования, списание попыток ИИ, наследование срока — помечены отдельно и не решаются незаметной правкой интерфейса.

В прототипе работают переключение вариантов, подсветка правок, изменение баллов Р5 с пересчётом исходного штрафа −1, перестановка трёх показанных критериев К6 и фильтрация восьми показанных строк К8. Отправка, сохранение, загрузка и переходы внутри продукта не выполняются.

## Проверка этой версии

Проверены синтаксис JavaScript, извлечение всех 22 экранов, применение всех 10 наборов изменений, наличие целей подсветки, режимы сравнения и переходы из реестра. Отдельно проверено сохранение цитат, девяти критериев и дополнительного поля Р5, исходного сигнала ИИ и штрафа, строк К8, событий К9. Проверка структуры выполнена вне браузера через DOM-парсер.

Полный визуальный просмотр новой версии в браузере не выполнен: доступ к локальному HTML через инструмент просмотра был заблокирован политикой браузера. Проверка DOM не подтверждает отсутствие визуальных наложений. Переключатели ширины и масштаба оставлены для приёмки в обычном браузере; ширина 1024 — стресс-тест, а не заявление о готовом адаптиве.

# Avito AI Reviewer

## Общее описание

Avito AI Reviewer - платформа проверки учебных работ, объединяет задания, критерии, работы и результаты проверки.

ИИ готовит предложения по критериям с обоснованиями. Ревьюер исправляет или подтверждает их и публикует оценку.

Методист распределяет работы и контролирует сроки. Студент сдает работу, получает обратную связь и вносит исправления.

Платформа сохраняет версии работ и критериев, историю проверки. DeepSeek harness управляет вызовами модели и проверками независимо от платформы.

Разработан прототип и проведен эксперимент на 60 работах. Результаты и ограничения приведены ниже. Ожидаемый эффект - сокращение времени проверки и нагрузки методиста. Его предстоит измерить в пилоте с ревьюерами.

## Проблематика

Материалы, статусы и переписка распределены между сервисами. Ревьюер вручную сопоставляет работу с критериями и предыдущими замечаниями. Методист отслеживает нагрузку и сроки. Ручная работа увеличивает затраты времени.

## Постановка задачи

Объединить сдачу, распределение работ, проверку работ и публикацию результатов.
Одна из главных метрик - время ревьюера на завершенную проверку, вторая, но менее измеряемая, - время методиста на организацию процесса ревью.

## Описание технического решения

Интерфейс: React и TypeScript. Бэкекнд: Python, FastAPI, MySQL. MinIO хранит материалы, Redis/Taskiq поддерживают фоновые задачи. Развертывание - Docker Compose.

Стек ИИ: модель `deepseek-v4-flash` и DeepSeek harness для подготовки материалов, вызовов модели и проверки результатов по критериям. Предусмотрены GitHub, Google Docs и загрузка файлов для получения работ, Stepik - для входа и передачи оценок. Интеграция со Stepik замокана.

## Полученные результаты

Модель `deepseek-v4-flash` выполнила 66 проверок по 22 заданиям: 431 оценка по критериям. Совпадение с референсными метками - **39/44 (88,64%)**. Precision - 91,67%, recall - 73,33%, F1 - 81,48%.

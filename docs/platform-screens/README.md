# Платформа: сущности и экраны

Всё, что описывает платформу целиком, а не только узкий сценарий хакатона: модель данных, макеты экранов по всем трём ролям и логика переходов между ними. Собрано в одной папке, чтобы можно было отсмотреть отдельно от остальных документов.

| Файл | Что внутри |
|---|---|
| [screens.html](screens.html) | 19 экранов, каждый кадром 1920 на 1080. Под каждым — назначение экрана и куда с него можно уйти |
| [flows.md](flows.md) | семь статусов домашки и кто их меняет, карта переходов по ролям, сводная таблица «функция, экран, переход», открытый вопрос по гарантии покрытия пула |
| [entities-and-screens.md](entities-and-screens.md) | 16 сущностей с обоснованием каждой, ER-диаграмма, реестр экранов со статусом (ядро MVP, видение, смакетирован) |

Данные на макетах вымышленные. Экраны выше 1080 отмечены пунктирной линией с границей первого экрана, ниже неё страница прокручивается.

Источник контекста — основной набор документов уровнем выше: [../03-platform.md](../03-platform.md) о том, зачем платформа устроена так, [../06-ux-and-effects.md](../06-ux-and-effects.md) про истории и эффект, [../04-contracts.md](../04-contracts.md) про то, что нельзя нарушать.

# Платформа: сущности и экраны

Всё, что описывает платформу целиком, а не только узкий сценарий хакатона: модель данных и макеты экранов по всем трём ролям. Собрано в одной папке, чтобы можно было отсмотреть отдельно от остальных документов.

| Файл | Что внутри |
|---|---|
| [all-screens.html](all-screens.html) | все 18 экранов в одной странице, каждый — стандартного десктопного размера, со сквозной навигацией по трём ролям |
| [entities-and-screens.md](entities-and-screens.md) | 16+ сущностей с обоснованием каждой, ER-диаграмма, полный реестр экранов по ролям со статусом (ядро MVP / видение / смакетирован) |

Раньше макеты лежали в четырёх отдельных файлах — они появились в разные моменты разговора, а не по плану, и два из них успели тихо разойтись с более поздними архитектурными решениями. Свели в `all-screens.html` и удалили исходные файлы, чтобы не оставлять в репозитории версию, которая незаметно устареет.

Данные на макете вымышленные. Источник контекста — основной набор документов на уровень выше: [../03-platform.md](../03-platform.md) (зачем платформа устроена так), [../06-ux-and-effects.md](../06-ux-and-effects.md) (истории и эффект), [../04-contracts.md](../04-contracts.md) (что нельзя нарушать).

# Платформа: сущности и экраны

Всё, что описывает платформу целиком, а не только узкий сценарий хакатона: модель данных и макеты экранов по всем трём ролям. Собрано в одной папке, чтобы можно было отсмотреть отдельно от остальных документов.

| Файл | Что внутри |
|---|---|
| **[all-screens.html](all-screens.html)** | **все 23 экрана в одной странице**, со сквозной навигацией по трём ролям — начните отсюда |
| [entities-and-screens.md](entities-and-screens.md) | 16+ сущностей с обоснованием каждой, ER-диаграмма, полный реестр экранов по ролям со статусом (ядро MVP / видение / смакетирован) |
| [screens.html](screens.html) | пять экранов узкого сценария хакатона отдельно: карточка работы, очередь ревьюера, дашборд координатора, настройка требований, саморевью студента |
| [pull-flow.html](pull-flow.html) | создание задания координатором, кабинет ревьюера с pull-очередью, состояние пула, ссылка для Stepik — отдельно |
| [accounts-and-stats.html](accounts-and-stats.html) | регистрация и настройки ревьюера, личная статистика, создание курса и потока, развёрнутая рубрика, статистика по всем ревьюерам — отдельно |
| [submission.html](submission.html) | сдача работы студентом: вход по ссылке из Stepik без отдельной регистрации, прикрепление артефакта, повторная сдача после доработки — отдельно |

Четыре файла ниже остались как есть — на них уже есть прямые ссылки в переписке. Но чтобы посмотреть все экраны подряд, открывайте `all-screens.html`, не их.

Данные на всех макетах вымышленные. Источник контекста — основной набор документов на уровень выше: [../03-platform.md](../03-platform.md) (зачем платформа устроена так), [../06-ux-and-effects.md](../06-ux-and-effects.md) (истории и эффект), [../04-contracts.md](../04-contracts.md) (что нельзя нарушать).

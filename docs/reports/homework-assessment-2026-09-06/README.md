# Оценка учебных работ

**Дата:** 6 сентября 2026. **Модель:** `deepseek-v4-flash`.

Корпус: [homework_examples](https://github.com/ai-talent-hub-avito/homework_examples/tree/7a72e08ab417f3ff6503467b51f5a58157fa833a), коммит `7a72e08`.

## Как проверяли

60 работ по 22 заданиям проверены через backend → reviewer-assist → prereview. Получено 66 ревью: каждый из трёх Go-репозиториев оценён отдельно по заданиям 1–3. Имена с метками качества скрыты от оценщика.

DOCX, PDF и Markdown переданы исходными файлами. Репозитории переданы ZIP-архивами; для Go выполнены `go build` и `go vet`. XLSX, HTML и notebooks преобразованы в Markdown с формулами, значениями ячеек, кодом и текстовыми результатами. Пропуски визуальных данных отмечены в подготовленных артефактах.

## Правила расчёта

- Хорошие работы относятся к нормальным. Средние оцениваются, но не входят в метрики классификации.
- Для работ с меткой «слабая», получивших зачёт ИИ, проведена отдельная проверка по условию и рубрике: достигшие порога относятся к нормальным, остальные — к слабым.
- Порог зачёта — 60% максимума. Для System Design №1 — 4/6, для №2 — 6/10; обязательные минимумы по критериям также учитываются.
- Критерий без предложенного балла получает максимальный балл при расчёте итога. Исходный ответ ИИ сохраняется.
- Положительный класс — **слабая работа**, положительный прогноз — **незачёт**.

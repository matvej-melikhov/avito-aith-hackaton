# Интервью 03 — Даша, PM Авито Академии, 3 сентября 2026

Источник: `sources/05-dasha-pm-transcript.txt`. Спикер 2 — Даша, PM Авито Академии; спикеры 1 и 3 — команда. Ответы про координацию — со слов PM, требуют валидации у методиста.

## Критерии и оценивание

- **Т12. Рубрика = пункты 0–3, хорошо/средне/плохо — бакеты по сумме.** «Хорошо — макс балл, среднее — средний, плохо — ниже среднего».
  - *Implication:* единый замер зачёта можно строить по сумме.
- **Т13. Критерии можно генерировать из условия.** Команда разрешила: «вы можете придумывать сам ... можно изгенерировать на основании задания». Сбор реальных табличек долгий, команда молодая.
  - *Implication:* для чекпоинта синтетическая рубрика допустима.
- **Т14. Пример Go-курса: 0/1 по автотесту или вручную, сумма в таблице.** Показана реальная ведомость прошлого года.
  - *Implication:* формальные проверки кодом — 1 балл.

## Google Sheets

- **Т15. Sheets — внутренняя, но обязательная.** Собирает оценки из Stepik/GitHub в одном месте, аналитика (кому не хватает баллов), раздача студентам (копия без ПДн) из-за отсутствия доступа к вузовской ИС.
  - *Цитата:* «нет единого пространства ... скидываем студентам ... самый простой способ»
  - *Implication:* подтверждает решение `источник истины — платформа, Sheets — выгрузка` `docs/03-platform.md`.

## Флоу

- **Т16. Платформы нет, есть Stepik + GitHub.** Задание получают в Stepik или GitHub, сдают туда же (Stepik-ответ или PR), дальше координатор распределяет.
- **Т17. Распределение после дедлайна, уведомление в Телеге.** «домашние распределены, можете приступать». Ревьюер не обязан мониторить таблицу до отбивки.
- **Т18. Не поровну, а по заявленной нагрузке.** «у меня высокая нагрузка, готов только два».
  - *Implication:* pull по ёмкости, а не equal split.
- **Т19. Два режима проверки + синхрон.** С исправлением до финального дедлайна (цикл повторяется) или один проход; плюс иногда 1-1 созвон по финальной работе.
  - *Implication:* статус `на доработке` и сравнение версий.

## ИИ-сигнал

- **Т20. Цель — подсветка, не санкция.** «Работа может быть полностью сгенерирована, но с умом — игнорируем. Нейрослоп — оставляем право не принимать, не тратим время».
  - *Цитата:* «подсвечено ... понимаем, что нейрослоп ... право эту работу не принимать»
  - *Implication:* сигнал с уровнями, желательна дифференциация `полностью сгенерено vs доработано` (пожелание).
- **Т21. Школьное направление — отдельный кейс, там запрет.** Для автовских курсов — развитие навыка работы с ИИ, для школ — пока запрет.
  - *Implication:* профиль с флагом `ИИ разрешён/запрещён`.

## Эффекты и платформа

- **Т22. Эффект — единый процесс и экономия времени ревьюеров + аналитика.** «проще анализировать ... единый процесс».
- **Т23. Саморевью — ок для проходных работ, показывать минимум.** «такие критерии ты не выполнил ... не показываем % ИИ». Для экзаменов — не подходит.
  - *Implication:* дизайн саморевью: без баллов и без сигнала ИИ.
- **Т24. Гибкая платформа — идея понятна, коллеги просят, но риск размытия фокуса.** «супер-апп ... возможно, сложная задача в рамках кейса ... не размывался фокус».
  - *Implication:* в коде — обобщённые интерфейсы, второй профиль внутри образования; на слайде — таблица профилей, не реальный CI.

# Spec Kit в этом репозитории

Версия: **1.0.4**, официальный исходник — `github/spec-kit`, тег `v1.0.4`.

## Где что находится

- `.agents/skills/speckit-*/` — навыки Codex для этого проекта и его подпапок.
- `.specify/` — шаблоны, скрипты и настройки Spec Kit.
- `specs/` — спецификации функций; появятся при создании первой спецификации.
- `scripts/specify` — локальная команда запуска CLI.
- `.cache/uv-speckit/` — среда Python, зависимости и кэш загрузки; исключены из Git.

Глобальная команда `specify` не устанавливается. Общие папки навыков Codex и настройки оболочки не меняются. Навыки этого репозитория не обнаруживаются из соседних проектов.

## Использование

В терминале из корня репозитория:

```sh
./scripts/specify --version
./scripts/specify integration status
```

Нужны `uv` и установленный Python 3.11+. При первом запуске CLI загружает зафиксированную версию и зависимости в локальный кэш. Автоматическая загрузка Python отключена. Кэш можно удалить: следующий запуск создаст его заново и потребует сеть.

В чате Codex этого проекта навыки вызываются по имени:

```text
$speckit-constitution
$speckit-specify <описание функции>
$speckit-clarify
$speckit-plan <технические ограничения>
$speckit-tasks
$speckit-analyze
$speckit-implement
$speckit-converge
```

Каждый вызов — отдельный этап. Установка не создаёт требования к продукту и не запускает разработку. Если новые навыки не появились, перезапустите Codex.

В Git передаются навыки, служебные шаблоны, спецификации, этот документ и скрипт запуска. Локальный кэш и машинное состояние, перечисленное в `.specify/.gitignore`, не передаются.

# Независимый usability-прогон after-s1-valid

Outcome: PARTIAL

Сдача человеку и проверка отправленного содержимого завершены. Узнать реальные замечания заранее не получилось: предварительная проверка показала демонстрационный результат без вызова модели.

## Выполненные цели и доказательства

- Нашёл «Первый API списка задач» курса «Практикум API · задания студентов», поток «Самостоятельная работа · новые задания».
- Загрузил new-api.md и добавил точное пояснение «Проверки ошибочных запросов включены в README.».
- Запустил «ИИ-ревью» до отправки. Получил «Перед отправкой стоит доработать работу», затем две строки «Демо: проверьте … Модель не вызывалась». Показано «За результат списана одна попытка», осталось 1 из 2.
- Нажал «Отправить на ревью». Карточка /#/submissions/01a07356-45d7-7a79-a475-85a2f64d09c1 показывает «Ожидает ревью», «Попытка 1», «Отправленная работа», new-api.md и точный комментарий.
- Открыл new-api.md из отправленной работы. В новой вкладке совпадает всё содержимое разрешённого исходного файла: GET /tasks, POST /tasks, пустой заголовок возвращает 400, три проверки с задачей «Прочитать документацию».
- Понятен следующий этап: «Работа отправлена на ревью. Результат появится после публикации». Конкретного срока ответа нет.

## Маршрут и ощущения по ходу

1. Главная «Мои домашки»: нужного задания среди двух работ нет. Ожидал найти новые задания через «Мои курсы», так и сделал.
2. Под нужным курсом два потока; «новые задания» естественно подходит первой сдаче. Открыл его, затем «Сдать работу».
3. На форме по умолчанию ссылка; переключил «Файлы». Форматы и лимит видны. Выбрал файл, ввёл комментарий. Статус «Черновик сохранён» и ссылка на сохранённый файл дают уверенность в сохранении.
4. Нажал отдельную кнопку «ИИ-ревью»: появился статус «Черновик», выполняющаяся проверка и счётчик попыток. Понял, что сдачи человеку ещё не произошло. Одно ожидание 1500 мс дало результат.
5. Результат вызвал недоверие: общая рекомендация доработать, но никаких предметных замечаний, обе строки прямо говорят о демо. Повторять не стал, поскольку второй запуск обещает потратить последнюю попытку без основания ждать полезной информации.
6. Подсказка «Можно отправить работу сейчас или сначала внести правки. Решение принимает ревьюер» позволила продолжить. Нажал отправку, увидел подтверждение и правильный комментарий.
7. Открыл файл из «Отправленная работа», сравнил видимый текст, вернулся к карточке сдачи. Ошибочных переходов и технических сбоев не было.

## Pain

1. Существенный: экран результата ИИ — «Перед отправкой стоит доработать работу» одновременно с «Демо: проверьте „Основной сценарий API“. Модель не вызывалась» и аналогичной строкой про ошибки. Ожидал замечания по моему файлу, получил общие названия критериев. Влияние: цель предварительно оценить работу не достигнута; рекомендация доработки не обоснована анализом. Минимальная идея: до запуска явно назвать режим демонстрационным, а на результате писать, что работа не оценивалась, без рекомендации доработать.
2. Существенный: тот же экран — «За результат списана одна попытка». Ожидал расход попытки за полезную проверку. Влияние: ощущение потери ограниченного ресурса за демо и нежелание повторять. Минимальная идея: не расходовать попытку за демонстрационный ответ, либо явно предупредить об этом перед запуском.
3. Небольшой: в шапке на всём пути профиль обозначен «75f5». Ожидал своё имя Алексей Иванов. Влияние: не могу по шапке подтвердить, под чьим именем сдаю работу; прохождение не остановило. Минимальная идея: показывать имя пользователя.

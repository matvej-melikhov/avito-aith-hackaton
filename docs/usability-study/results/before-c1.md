# before-c1 — подготовка учебной программы

Outcome: SUCCESS_WITH_FRICTION. Поток и задание опубликованы, требования проверены после перезагрузки через UI. Ссылка показана после публикации и зафиксирована, однако повторное получение ссылки после перезагрузки не обнаружено. Студенческую доступность самой ссылки не проверял: ссылка представлена текстовым полем, перехода по ней в разрешённых действиях нет.

## Цели и доказательства

- Курс: «Практикум · учебная программа». Другие курсы не редактировал.
- Поток: «Практикум · учебная программа · 2026-10-01». Карточка показывает 1 окт. 2026 г., 00:00 — 15 нояб. 2026 г., 23:59. UI route: #/courses/01a07316-03e5-7a51-b6dc-e05e0e68f480.
- Задание: «Контракты HTTP». Условие после reload: «Опишите HTTP API: методы, пути, параметры запросов и структуру ответов. Опишите обработку ошибок: HTTP-коды, формат сообщения об ошибке и примеры ошибочных запросов.»
- Критерий «Описание API», 5 баллов: «Описаны методы, пути, параметры запросов и структура успешных ответов HTTP API.»
- Критерий «Обработка ошибок», 5 баллов: «Указаны HTTP-коды ошибок, единый формат сообщения об ошибке и примеры ошибочных запросов с ответами.» Оба повторно просмотрены после reload; порог 6 из 10.
- Лимит AI-самопроверок: 2, подтверждён после reload.
- Выбран режим «Ссылка или файлы». Сохранённый выбор визуально подтверждён снимком 004 после reload.
- Сдать до: 2026-10-15T23:59. Проверить до: 2026-10-20T23:59. Оба значения сохранены после reload.
- Публикация: UI сообщил «Задание и лимит опубликованы», выдал ссылку http://127.0.0.1:5180/#/prepare/01a07316-559d-74e0-a502-e87f5993fed3. После reload показывает «Публикация 5 сент. 2026 г., 22:42 · срок 15 окт. 2026 г., 23:59». Задание присутствует в опубликованном списке потока, баллы 10.
- Дополнительные правила оставлены исходными: 7 дней на доработку, 3 пересдачи, без штрафа. Время окончания дня принято самостоятельно, поскольку сценарий задавал даты без времени.

## Маршрут

Обзор → Создать поток → выбрать целевой курс, заполнить даты → ошибка → Отмена → Курсы → целевой курс (оказалось редактирование курса, отменено) → Задания → Создать задание (нужного потока нет) → отмена → Обзор → повторное создание потока с теми же значениями, успешно → открыть поток → создать задание по названию → условие/формат/срок/самопроверки → критерии и порог → публикация → reload → просмотр каждого шага → возврат в поток.

## Боли

1. Экран «Создать поток», фраза «The request could not be completed». Ожидание: после валидных дат создать поток либо объяснить исправление. Факт: общая английская ошибка без причины; после обхода через другие страницы повтор тех же значений сработал. Влияние: едва не остановил весь сценарий; потратил время на поиск альтернативы. Минимальная идея: понятная причина и безопасный повтор, сохранение заполненной формы. Причину сбоя по UI установить нельзя.
2. «Курсы» → название курса. Ожидание: открыть курс и его задания/потоки. Факт: сразу открывает модальное редактирование метаданных. Влияние: ложный маршрут в поиске способа создать поток. Минимальная идея: страница курса по названию, отдельная кнопка редактирования.
3. «Новое задание» → «Курс и поток». Ожидание: подготовить задание в существующем курсе независимо от потока. Факт: целевого курса без потока нет в вариантах; пояснение при этом говорит, что задание сохраняется в курсе. Влияние: ошибка создания потока блокирует даже независимую подготовку задания. Минимальная идея: разрешить черновик задания в курсе, поток выбирать перед публикацией.
4. Шаг «Публикация» после reload. Ожидание: повторно получить ссылку опубликованного задания. Факт: поле «Ссылка для Stepik» и копирование исчезли; остаётся «Опубликовать задание» и строка прежней публикации. В потоке ссылка «Открыть» возвращает к настройке. Влияние: риск повторной публикации ради ссылки; приходится сохранять её сразу. Минимальная идея: постоянно показывать ссылку существующей публикации и статус.
5. Таблица заданий потока, «ФОРМАТ: github, google_docs». Ожидание: увидеть разрешённую загрузку файла. Факт: формат перечисляет технические названия ссылок, хотя сохранённый режим — «Ссылка или файлы». Влияние: сомнение, действительно ли студент сможет загрузить файл. Минимальная идея: выводить тот же понятный режим, что выбран в форме.
6. Поля дат в русской форме визуально показывают 10/15/2026, 11:59 PM. Ожидание: русское отображение даты/времени. Факт: native-поле с американским представлением. Влияние: дополнительная проверка дат. Минимальная идея: явная подпись часового пояса и согласованный формат отображения рядом.

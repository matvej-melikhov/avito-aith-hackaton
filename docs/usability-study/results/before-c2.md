## Боли

1. Экран пула, «Только зависшие».
   Ожидание: увидеть работу со сроком проверки 3 сентября на текущую дату 5 сентября.
   Факт: до фильтра есть «API каталога», после — «Незавершённых проверок по этим условиям нет». Счётчик «ждут больше 3 дней» тоже 0.
   Влияние: координатор может пропустить просроченную активную проверку.
   Минимальная идея: отдельный явно названный фильтр «Срок проверки истёк» для всех незавершённых проверок; пояснить смысл существующего фильтра.

2. Карточка проверки, «Других участников: 1».
   Ожидание: понять, кто именно проверяет.
   Факт: только число без имён и без раскрытия; имя Елены найдено лишь в реестре.
   Влияние: приходится совмещать сведения с разных экранов; смысл «других» неочевиден координатору.
   Минимальная идея: имена участников и их роль прямо рядом с числом.

3. Боковые «Пул проверок» и «Домашки».
   Ожидание: сохранить текущий поток.
   Факт: оба перехода сбрасывают на «Самостоятельная работа · доработка» другого курса.
   Влияние: дополнительные выборы и риск работы/выгрузки не того потока.
   Минимальная идея: сохранять выбранный поток при переходах.

4. Курсы → название курса.
   Ожидание: открыть курс и его потоки.
   Факт: открывается «Редактировать курс», приходится отменять и возвращаться в Обзор.
   Влияние: лишний маршрут к назначению ревьюера.
   Минимальная идея: название ведёт в карточку курса, редактирование отдельной кнопкой.

5. «История и результат» для текущей проверки.
   Ожидание: увидеть историю работы ревьюера и участников.
   Факт: статус «Ожидает ревью» и только событие «Сдана», хотя реестр говорит «На проверке».
   Влияние: противоречивое ощущение, начата проверка или нет.
   Минимальная идея: согласовать статус со стадией проверки и назвать ссылку «Результат для студента», если это назначение страницы.

6. Сохранение основного ревьюера.
   Ожидание: явное подтверждение сохранения и границы влияния.
   Факт: после клика в видимом тексте нет подтверждения; пришлось перезагрузить страницу. Общий абзац о закреплении полезен.
   Влияние: сомнение, сохранён ли выбор.
   Минимальная идея: «Дмитрий назначен для следующих работ. Начатые проверки не изменены».

7. CSV студенческой ведомости.
   Ожидание: понятная студенту строка результата.
   Факт: полный UUID вместо короткого ID, статус passed вместо «Зачтена», нет названия задания при выгрузке всех заданий.
   Влияние: ведомость безопасна по приватности, но без дополнительного контекста плохо читается и не позволяет различить задания при большем числе строк.
   Минимальная идея: добавить название задания и русское название статуса в разрешённые публичные поля.

# API списка задач

Реализован GET /tasks: возвращает JSON-массив задач с идентификатором и заголовком.
POST /tasks создаёт задачу. Пустой заголовок возвращает 400.

## Проверки

- Создать задачу с заголовком «Прочитать документацию».
- Убедиться, что задача появилась в списке.
- Передать пустой заголовок и проверить код ошибки.

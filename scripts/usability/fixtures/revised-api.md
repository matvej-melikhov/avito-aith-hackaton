# Исправленная обработка ошибок API

GET /tasks возвращает список задач.
POST /tasks проверяет обязательный заголовок; пустой заголовок возвращает 400.
Фильтр completed принимает только true или false; другое значение возвращает 400.

## Проверки после замечаний

Добавлены сценарии пустого заголовка, неизвестного значения фильтра и успешного создания задачи.

# Источники

Исходные материалы в неизменённом виде — для того, чтобы к ним можно было обращаться и людям, и агентам.

| Файл | Что это |
|---|---|
| [01-case-description.md](01-case-description.md) | краткое описание кейса «Avito AI Reviewer» — исходная постановка задачи |
| [02-avito-draft-task.pdf](02-avito-draft-task.pdf), [текстовая версия](02-avito-draft-task.txt) | «Авито AITH, драфт задачи для хакатона». Расширенный контекст: детальное описание текущего процесса, курсы, критерии успеха |
| [03-day2-setup-ai-product-hack.pdf](03-day2-setup-ai-product-hack.pdf), [текстовая версия](03-day2-setup-ai-product-hack.txt) | «Установка 2-го дня, AI Product Hack». Порядок работы на неделе, требования к артефактам, дедлайны, критерии защиты |

Текстовые версии получены из PDF командой `pdftotext -layout`, они удобны для поиска и для агентов. Исходные PDF оставлены без изменений.

Данные для разработки (примеры домашних работ) не хранятся в этом репозитории — они лежат в
